The notebook gives each piece of work its own tab. Notes can stay simple, or use Markdown for structure when the content calls for it.

## Write and format

Use headings for sections, bullets for details, and checkboxes for action items. The formatted preview lets you review the result without losing the editable Markdown source.

```markdown
# Website review

## Decisions
- Keep the first release focused on the download flow.

## Action items
- [ ] Sam: share revised mockups by Friday.
- [ ] Alex: confirm the installation copy.
```

## Drafts and saved notes

An editable draft is the place to review new text before saving it as a note. Check AI-organized details, owners, dates and decisions against the conversation. AI output and transcription can contain mistakes.

Meeting text can be added to the current note draft or used to replace its text when you explicitly select that option. Review the replacement choice before applying it.

In meeting review, **Save note** creates the linked note; **Update note** updates a linked note that already exists. The recording and transcript remain associated with the meeting.

## Keep a notebook organized

Use folders to group related notes and recordings. Search for a phrase when you remember the content but not the title. Archive work you want to keep outside the active view.

Keyboard navigation between notebook tabs supports arrow keys, Home and End. Closing a tab restores focus to an appropriate remaining control.

## AI assistance

The note assistant can help summarize saved notes, extract tasks, or organize existing text. Its answers depend on the notes supplied and your configured provider. Check the result before applying it.

## Managed Markdown copies

Noter.ai maintains human-readable Markdown copies in the configured library. Assistant updates also sync to managed files. If an external edit conflicts with an app update, the app reports the conflict rather than silently replacing the external change.

See [local files and backups](../storage/) before editing or reorganizing library files outside the app.
