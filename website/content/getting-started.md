Noter.ai brings a tabbed notebook, meeting capture and searchable recordings into one desktop app. Write a quick note on your own, or turn a conversation into an organized draft you can review.

## Install the desktop app

Choose your operating system on the [download page](../../download/). Windows has a Setup installer and MSI. Mac downloads are separate for Apple Silicon and Intel. Linux has AppImage and Debian packages.

The current desktop release is an **experimental, unsigned release candidate**. Linux currently supports notes and review of existing recordings, with live capture unavailable. Read the relevant installation guide before downloading.

## Make your first note

1. Open Noter.ai and complete the initial account setup if prompted.
2. Create a note with the new-note control.
3. Write in the editor. Use Markdown for headings, lists and checkboxes.
4. Review the text, then use the save control to save the note.

Keep work in a folder when you want a little more structure. See [notes, drafts and folders](../notes/) for the difference between editing a draft and saving a note.

## Connect your AI

Open **Settings > AI & meetings**. Choose an AI connection and model for organizing notes and answering questions. Set up a transcription provider separately for meeting audio.

You use your own eligible account or provider API key. Noter.ai has no subscription, but external providers can have their own costs and usage limits. See [AI connections](../ai-connections/).

## Try a meeting

On supported platforms, open the meeting companion, choose your capture sources, and start recording. Select the meeting tab, window or screen and enable audio sharing when your system offers it.

When the meeting ends, review the organized draft before saving. A saved recording can be reopened alongside its transcript and linked notes.
